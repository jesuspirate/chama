# Community banner — corrected native branding

Supersedes v1, whose generated wordmark was incorrect.

The symbol is the unchanged repository asset `landing/icons/chama-mark-512.png`. The lowercase lettering uses actual Manrope 800 glyph outlines, matching the landing page's `.brand` font and letter spacing. The orange dot uses the `.brand-dot` color. These brand elements are composited directly, never generated or redrawn by the image model.

Built-in image editing was used only to remove the incorrect upper-left wordmark from v1. Prompt: erase that wordmark and its period into the existing forest-green background, leaving the region empty; preserve the people, photo, phone, basket, both headline lines, colors, and canvas ratio. Exact native branding was then overlaid as vector glyphs and the repository PNG.

Final output: 2172×724 PNG, 3:1 community header. Existing landing hero and Open Graph card are unchanged.
