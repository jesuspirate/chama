# Bitcoin mark

`bitcoin-official.png` is the unmodified 256px Bitcoin icon distributed in Bitcoin Core:
https://github.com/bitcoin/bitcoin/blob/master/share/pixmaps/bitcoin256.png

Downloaded from the corresponding raw GitHub asset. It is used as an image, never substituted with a font glyph or redrawn in CSS. Bitcoin Core is distributed under the MIT license: https://github.com/bitcoin/bitcoin/blob/master/COPYING

`chama-circle-dark.svg` is copied unchanged from the application's `public/icons/verticals/chama-dark.svg`, the create-form savings-circle mark.
