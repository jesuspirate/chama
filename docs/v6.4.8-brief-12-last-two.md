## 1. After a trade settles, back goes Home (app repo — Codex)

The buyer who opened the trade from the offers list still sees **‹ Offers**
after the trade completes; the seller sees **‹ Home**. The offers list is the
right destination while the person might still change their mind. Once the
trade is over it's a stale search.

`App.tsx:4005` and `:4130` pick the label from `detailBackView === "guided"`
and `detailReturnsHome`. Make `detailReturnsHome` true whenever the open
trade is in a terminal state (COMPLETED, CANCELLED, EXPIRED, and a settled
REFUND), and make the back action match the label — Home, with the guided
flow reset, not the old offers snapshot. Before settlement nothing changes.

Test: a guided-opened trade shows Offers while CREATED/LOCKED and Home once
COMPLETED, and pressing it lands on the guided Home.

## 2. Start9 shows the dev banner (packaging repo — not this repo)

On StartOS the header reads **v6.4.7 · dev 09-22 21:28 · native**.
`vite.config.ts:14-16` only removes the build stamp when `CHAMA_RELEASE=1`;
`ship.sh:117` exports it, so the web and Zapstore builds are clean. But
StartOS doesn't use our build — it builds from source in
`chama-startos/Dockerfile`, line 15:

```dockerfile
RUN VITE_CHAMA_NATIVE_BRIDGE_REQUIRED=1 VITE_CHAMA_NATIVE_BRIDGE_URL=/bridge npm run build
```

No `CHAMA_RELEASE`, so every Start9 package ships the amber dev stamp, and
the `· native` session badge rides along with it (`App.tsx:3344` only shows
the badge when a stamp exists).

Fix, one line, in **Start9-Community/chama-startos**:

```dockerfile
RUN CHAMA_RELEASE=1 VITE_CHAMA_NATIVE_BRIDGE_REQUIRED=1 VITE_CHAMA_NATIVE_BRIDGE_URL=/bridge npm run build
```

Per `AGENTS.md`, packaging changes belong in that repo, not this one. Note
that `scripts/start9-release.sh:117` does `git checkout -B chama-vX.Y.Z
upstream/main`, so a local commit made in the checkout beforehand is thrown
away. Add it **after** the ship run opens the 6.4.8 PR: check out that branch,
make the one-line change, commit, push — it joins the same PR, and once Matt
merges it every future Start9 release inherits it.
