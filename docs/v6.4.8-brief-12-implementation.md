# Brief 12 implementation and release handoff

## App navigation

The open trade's back destination is derived from its current state, so label and action change together without waiting for an effect. A guided offer retains Offers while CREATED/LOCKED and while an approved/claimed payout is still unsettled. COMPLETED, CANCELLED and EXPIRED return Home. A CLAIMED REFUND also returns Home when its payout journal records settlement, even if the COMPLETE event has not arrived yet.

The room, full trade detail and circle detail share the back handler. Returning to guided Home calls the existing reset: clear the saved search snapshot, clear the publication result, clear the selected trade, and remount the guided canvas on Home. Expiry here is only a navigation decision; escrow recovery semantics and money guards are unchanged.

Verification: typecheck, full npm tests, build, repository hygiene, and a browser regression that starts with an Offers-origin trade, verifies Offers in CREATED and LOCKED, changes it to COMPLETED, clicks Home, and verifies the guided starting choices with the saved search cleared. Unit cases also cover CANCELLED, EXPIRED, and settled versus unsettled refunds.
