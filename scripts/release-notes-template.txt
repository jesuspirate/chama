Chama release-notes template
============================
See scripts/ship.sh and docs/RELEASING.md.

For each release, save TWO files in $CHAMA_COMMIT_DIR (default /tmp), named for
the TARGET version (the version you're about to ship, i.e. after the bump):

  /tmp/chama-v<VERSION>_release_notes     (required)
  /tmp/chama-v<VERSION>_zapstore_notes    (optional)

ship.sh resolves both by name and refuses to start if the required one is
missing, so a typo can never leave you with a half-bumped tree.


── chama-v<VERSION>_release_notes ───────────────────────────────────────────
Line 1 is the commit subject in the repo convention (the leading vX.Y.Z must
match the version you're shipping — ship.sh warns if it doesn't). Everything
below is the commit body, and also the long GitHub release notes when
release:all is given --notes-file pointing at this same file.

    v<VERSION> — short subject, comma, separated, imperative

    Optional longer body for the engineering audience / GitHub release.
    - bullet one
    - bullet two


── chama-v<VERSION>_zapstore_notes (separate file) ──────────────────────────
Curated, user-facing notes shown on the Zapstore app card. This format is a
release protocol, not a suggestion:

    # Theme Name

    ⚡ One-line benefit tagline.

    🧰 First concrete user benefit.

    🌍 Second concrete user benefit.

    🛡️ Reliability or safety benefit.

    N tests green · production build passed · physical-device verified

Rules:

- Start with one `# Theme` title. Do not put the version in this title.
- Follow with a one-line ⚡ tagline.
- Use emoji-led benefit bullets as separate paragraphs.
- Keep a BLANK LINE between every emoji bullet; Zapstore collapses ordinary
  single newlines and the card becomes an unreadable paragraph otherwise.
- End with a short `·`-separated proof closer.
- Never substitute a generic one-paragraph summary.

`scripts/validate-zapstore-notes.mjs` enforces this shape before publication.
Omit the file only for a dev-only release; public releases require curated
notes.
